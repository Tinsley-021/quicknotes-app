# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organise, search and delete notes. Notes can be placed into Personal, Work or Study categories, and they are saved in the browser so they remain available after refreshing the page.

## Features

- Add notes
- Personal, Work and Study categories
- Delete individual notes
- Search notes
- Validate empty notes
- Limit notes to 200 characters
- Display the number of notes
- Save notes using localStorage
- Load notes after refreshing
- Clear all notes
- Show the date and time for each note
- Responsive design for smaller screens

## How to run the project locally

1. Download or clone the repository.
2. Open the `quicknotes-app` folder.
3. Open `quicknotes-app.html` in a web browser.
4. Start adding notes.

No additional software or server is required.
